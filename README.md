# jonts.ai

Home of Jonathan Tsai's personal AI assistant / doppelganger at https://www.jonts.ai.

This is a static Next.js site following the nextjs-htk GitHub Pages pattern: `next build` exports into `docs/`, and `CNAME` points GitHub Pages at `www.jonts.ai`.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
